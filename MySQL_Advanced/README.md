## MySQL Advanced

This project is about learning to use MySQL.

* [0-uniq_users.sql](0-uniq_users.sql), a script creating a basic `users` table.

* [1-country_users.sql](1-country_users.sql), a script creating a `users` table with a `country` column.

* [2-fans.sql](2-fans.sql), a script selecting the countries of metal bands ranked by their number of fans.

* [3-glam_rock.sql](3-glam_rock.sql), a script selecting glam rock bands ranked by lifespan.

* [4-store.sql](4-store.sql), a script triggering a quantity update after an order.

* [5-valid_email.sql](5-valid_email.sql), a script triggering a `valid_email` reset after an email change.

* [6-bonus.sql](6-bonus.sql), a script creating a stored procedure to add a correction to a student.

* [7-average_score.sql](7-average_score.sql), a script creating a stored procedure to compute an average score.

* [8-index_my_names.sql](8-index_my_names.sql), a script creating an index for `names` table with the `name` first letter.

* [9-index_name_score.sql](9-index_name_score.sql), a script creating an index for `names` table with the `name` first letter and `score`.

* [10-div.sql](10-div.sql), a script creating a function to divide safely a number by another.

* [11-need_meeting.sql](11-need_meeting.sql), a script creating a view listing students having a score under 80 and no recent meeting.

* [100-average_weighted_score.sql](100-average_weighted_score.sql), a script creating a stored procedure to compute and update an average weighted score for a user.

* [101-average_weighted_score.sql](101-average_weighted_score.sql), a script creating a stored procedure to compute and update an average weighted score for all users.

* [metal_bands.sql](metal_bands.sql), a SQL dump of metal bands.

* [names.sql](), a SQL dump of names.
