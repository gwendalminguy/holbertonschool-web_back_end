# Web Back-End

This repository focuses on back-end web development concepts.

* [Python - Variable Annotations](https://github.com/gwendalminguy/holbertonschool-web_back_end/blob/main/python_variable_annotations), a project to learn about writing variable annotations in Python.

* [Python - Async Functions](https://github.com/gwendalminguy/holbertonschool-web_back_end/blob/main/python_async_function), a project to learn about using async functions and concurrency in Python.

* [Python - Async Comprehension](https://github.com/gwendalminguy/holbertonschool-web_back_end/blob/main/python_async_comprehension), a project to learn about using async comprehension and generators in Python.

* [Pagination](https://github.com/gwendalminguy/holbertonschool-web_back_end/blob/main/pagination), a project to learn about implementing pagination in Python.

* [NoSQL](https://github.com/gwendalminguy/holbertonschool-web_back_end/blob/main/NoSQL), a project to learn about using NoSQL databases.

* [JavaScript - ES6 Basics](https://github.com/gwendalminguy/holbertonschool-web_back_end/blob/main/ES6_basic), a project to learn about using JavaScript basics.

* [JavaScript - ES6 Classes](https://github.com/gwendalminguy/holbertonschool-web_back_end/blob/main/ES6_classes), a project to learn about using classes in JavaScript.

* [JavaScript - ES6 Data Manipulation](https://github.com/gwendalminguy/holbertonschool-web_back_end/blob/main/ES6_data_manipulation), a project to learn about manipulating data in JavaScript.

* [JavaScript - ES6 Promises](https://github.com/gwendalminguy/holbertonschool-web_back_end/blob/main/ES6_promise), a project to learn about using promises in JavaScript.

* [NodeJS Basics](https://github.com/gwendalminguy/holbertonschool-web_back_end/blob/main/Node_JS_basic), a project to learn about using NodeJS basics.

* [Caching](https://github.com/gwendalminguy/holbertonschool-web_back_end/blob/main/caching), a project to learn about implementing caching systems in Python.
