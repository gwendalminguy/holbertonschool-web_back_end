# Web Back-End

This repository focuses on back-end web development concepts.

* [Python - Variable Annotations](python_variable_annotations/), a project to learn about writing variable annotations in Python.

* [Python - Async Functions](python_async_function/), a project to learn about using async functions and concurrency in Python.

* [Python - Async Comprehension](python_async_comprehension/), a project to learn about using async comprehension and generators in Python.

* [Pagination](pagination/), a project to learn about implementing pagination in Python.

* [NoSQL](NoSQL/), a project to learn about using NoSQL databases.

* [JavaScript - ES6 Basics](ES6_basic/), a project to learn about using JavaScript basics.

* [JavaScript - ES6 Classes](ES6_classes/), a project to learn about using classes in JavaScript.

* [JavaScript - ES6 Data Manipulation](ES6_data_manipulation/), a project to learn about manipulating data in JavaScript.

* [JavaScript - ES6 Promises](ES6_promise/), a project to learn about using promises in JavaScript.

* [NodeJS Basics](Node_JS_basic/), a project to learn about using NodeJS basics.

* [Caching](caching/), a project to learn about implementing caching systems in Python.

* [Personal Data](personal_data/), a project to learn about handling personal data through obfuscated logging and password hashing.

* [Basic Authentication](Basic_authentication/), a project to learn about implementing a basic authentication system.

* [Session Authentication](Session_authentication/), a project to learn about a session system for authentication.

* [User Authentication Service](user_authentication_service/), a project to learn about implementing a user authentication service.

* [Unittests & Integration Tests](Unittests_and_integration_tests/), a project to learn about unit and integration tests.

* [i18n](i18n/), a project to learn about translation.

* [Redis Basic](0x0B_redis_basic/), a project to learn about Redis.

* [MySQL Advanced](MySQL_Advanced/), a project to learn about MySQL.
