## Unittests & Integration Tests

This project is about learning to write unit and integration tests.

### Files

* [client.py](https://github.com/gwendalminguy/holbertonschool-web_back_end/tree/main/Unittests_and_integration_tests/client.py), a module for a simple GitHubOrg client.

* [fixtures.py](https://github.com/gwendalminguy/holbertonschool-web_back_end/tree/main/Unittests_and_integration_tests/fixtures.py), test fixtures.

* [utils.py](https://github.com/gwendalminguy/holbertonschool-web_back_end/tree/main/Unittests_and_integration_tests/utils.py), a module with utility functions.

* [test_utils.py](https://github.com/gwendalminguy/holbertonschool-web_back_end/tree/main/Unittests_and_integration_tests/test_utils.py), tests for the `utils` module.

* [test_client.py](https://github.com/gwendalminguy/holbertonschool-web_back_end/tree/main/Unittests_and_integration_tests/test_client.py), tests for the `client` module.
